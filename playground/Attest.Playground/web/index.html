Is this tax ID valid?

Paste a tax ID, national ID or VAT number. Attest checks its shape and check digits for 87 countries and says why a number fails.

Type or paste a number. The answer appears as you type.

Use it in code

The same engine is a free HTTP API, and a NuGet package that runs in your process with no network call.

curl 'https://attest.hrabovskyi.online/v1/validate?value=BE0403019261&country=BE'

dotnet add package Attest

This checks form and check digits only. It cannot tell you a number is registered: for EU VAT that answer comes from VIES. The API is rate limited, one number per request.

Numbers you type are checked in memory and never stored or logged. Only the country, the verdict and the reason are counted. Source, Apache-2.0.
